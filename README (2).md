# Secure Password Manager & Generator

A secure, lightweight, and native Python command-line utility designed to generate highly secure random passwords and safely store them locally in an encrypted or structured format.

## Features
- **Customizable Password Generator:** Generates passwords with customizable lengths and optional inclusion of uppercase letters, numbers, and special characters.
- **Local Storage Management:** Saves your generated credentials safely in a structured local file (`passwords.txt`) with timestamps.
- **Zero External Dependencies:** Built purely using Python's standard libraries (`secrets`, `string`, `os`), ensuring maximum portability and safety.

## How to Run Locally

1. Make sure you have **Python 3.x** installed.
2. Download the `password_manager.py` file.
3. Open your terminal or command prompt and execute:
   ```bash
   python password_manager.py
   ```
4. Follow the on-screen menu to generate, view, or manage your passwords.
